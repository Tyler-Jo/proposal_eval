## 2. 단위 테스트(Unit Test) 상세 명세

### 1️⃣ Test 01. 대용량 PDF 청크 분할 및 메모리 점유율 테스트 (`test_01_pdf_chunking.py`)
* **목적:** 수백 페이지 스캔 PDF 스트리밍 파싱 시 RAM 폭발 방지 및 가비지 컬렉션(`gc.collect()`) 검증
* **요구사항:**
  * 대용량 PDF를 `chunk_page_size` (예: 30장, 50장) 단위로 끊어서 읽는 스트리밍 파싱을 수행한다.
  * `psutil` 모듈로 각 청크 처리 전후의 RAM 사용량을 측정하고, `gc.collect()` 호출 후 메모리가 안정적으로 비워지는지(`assert`) 검증한다.

### 2️⃣ Test 02. 정량 평가 - 블라인드 위반 검출 & 오탐/미탐 대응 테스트 (`test_02_quant_blind.py`)
* **목적:** 업체명/로고 감점 처리 시 화이트리스트(오탐 방지) 및 수동 검증 인터페이스 데이터 구조 검증
* **요구사항:**
  * **화이트리스트 필터링:** '발주기관명', '참조 규격 내 타사명' 등 예외 사전(Whitelisting)을 적용하여 오탐 감점을 방지하는지 검증한다.
  * **시각적 근거 좌표 반환:** 위반 검출 시 UI 하이라이팅을 위한 Bounding Box 좌표(`bbox: [x0, y0, x1, y1]`)와 해당 영역 이미지 캡처 데이터를 포함한 결과 객체를 생성하는지 검증한다.
  * **검토 상태값 제공:** 결과 객체의 기본 상태를 `"status": "PENDING_REVIEW"`로 설정하여, 사용자가 UI에서 "승인(CONFIRMED)" 또는 "오탐 취소(DISMISSED)"를 선택할 수 있게 구조화되어 있는지 `assert`한다.

---

### 3️⃣ Test 03. 정량 평가 - B권 [목차 + 상단 ROI OCR] 기반 초고속 증빙 서류 검사 (`test_03_quant_b_documents.py`)
* **목적:** B권 전반부 목차 파싱 및 페이지 상단 중앙(Top-Center ROI) 텍스트 전용 OCR을 통한 초고속 증빙서류 판정
* **요구사항:**
  1. **전체 목차 트리 파싱 (B권 1~15P):**
     * B권 전반부 텍스트에서 로마자/숫자 패턴(`I.`, `1.`, `가.`)을 분석하여 증빙 목록과 목표 페이지(`declared_page`) 트리를 생성하는지 검증한다.
  2. **상단 중앙 영역(Top 25% ROI) Target OCR:**
     * 전체 페이지를 OCR하지 않고, 목표 페이지 및 인접 페이지의 **상단 20~30% 영역(Bounding Box)만 자른(Crop) 이미지**로 OCR을 수행하는 모듈이 정상 동작하는지 검증한다.
     * 상단 영역 텍스트에서 문서 제목(예: "적합등록필증", "이행확약서", "TTA인증서")을 추출하여 서류 존재 여부를 판정한다.
  3. **수동 추가(Manual Override) 감점 지원:**
     * AI가 미탐(False Negative)한 서류를 사용자가 UI에서 수동 추가할 경우, 기존 검출 리스트와 병합되어 감점 총점이 재산출되는지 `assert`한다.
